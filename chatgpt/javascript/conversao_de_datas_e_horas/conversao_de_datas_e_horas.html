Manipulando datas

Obs: para usar as funções tipo data insira este código:

<script language="javascript" src="data.js"></script>

Definindo o dia da semana

Sintaxe:

dia_da_semana(data) // retorno: semana

Exemplo:

dia_da_semana("31/07/2009") // resultado: "Sexta"

Teste:

dia_da_semana( );
