🚀 Tutorial Megusta

Aprenda a escrever código uma vez e executar em múltiplas linguagens

📌 O que é Megusta?
Megusta é uma linguagem de programação e transpilador que permite escrever código em uma sintaxe única e depois "transpilar" para diversas linguagens: Python, JavaScript, Java, PHP, C, Clipper/Harbour, Rust, e outras.

📦 Instalação

Python

import sys sys.path.append('ouka') import ouka.Megusta as mg r = mg.Megusta()

JavaScript

<script src="ouka/Megusta.js"></script> <script> let r = new Megusta(); </script>

Java

import ouka.Megusta; public class Main { public static void main(String[] args) { Megusta r = new Megusta(); } }

PHP

<?php require "ouka/Megusta.php"; $r = new Megusta(); ?>

📝 Entrada e Saída

Imprimindo textos

// Python r.rPrint("Sem quebra") // Imprime sem quebra de linha r.rPrintln("Com quebra") // Imprime com quebra de linha r.rPrintln() // Apenas quebra de linha // JavaScript r.rPrint("Sem quebra") r.rPrintln("Com quebra") r.rPrintln() // Java r.rPrint("Sem quebra") r.rPrintln("Com quebra") r.rPrintln()

Lendo entrada do usuário

nome = r.rInput("Digite seu nome: ") r.rPrintln("Olá, " + nome + "!")
Digite seu nome: João Saída: Olá, João!

📝 Manipulação de Strings

Método Descrição Exemplo
strReplace() Substitui substring r.strReplace("Olá mundo", "mundo", "Megusta")
strLength() Tamanho da string r.strLength("Olá") → 3
strSubstring() Extrai substring r.strSubstring("Olá mundo", 0, 3)
strCharAt() Caractere na posição r.strCharAt("Olá", 0) → "O"
strIndexOf() Índice da substring r.strIndexOf("Olá mundo", "mundo") → 4
strLastIndexOf() Último índice r.strLastIndexOf("aaa", "a") → 2
strToLowerCase() Converte para minúsculas r.strToLowerCase("OLÁ") → "olá"
strToUpperCase() Converte para maiúsculas r.strToUpperCase("olá") → "OLÁ"
strEquals() Compara strings r.strEquals("Olá", "Olá") → true
strSplit() Divide string em array r.strSplit("a,b,c", ",") → ["a", "b", "c"]
strPadStart() Preenche início r.strPadStart("Olá", 6, "0") → "0Olá"
strPadEnd() Preenche final r.strPadEnd("Olá", 6, "0") → "Olá000"
strSearch() Busca regex r.strSearch("abc123", r"\d+") → 3

📅 Trabalhando com Datas

Método Descrição Retorno
dateDay() Dia do mês 1-31
dateWeekDay() Dia da semana 1=Domingo, 7=Sábado
dateMonth() Mês 1=Janeiro, 12=Dezembro
dateYear() Ano Ex: 2025
dateHour24() Hora (24h) 0-23
dateMinute() Minuto 0-59
dateSecond() Segundo 0-59

Exemplo completo

dia = r.dateDay() mes = r.dateMonth() ano = r.dateYear() semana = r.dateWeekDay() r.rPrintln(f"Hoje é {dia}/{mes}/{ano}") r.rPrintln(f"Dia da semana: {semana}")
Hoje é 26/09/2025 Dia da semana: 6

📊 Arrays

Método Descrição
arrAdd() Adiciona elemento
arrAddAll() Adiciona vários elementos
arrSet() Define elemento na posição
arrGet() Obtém elemento na posição
arrSize() Tamanho do array
arrRemove() Remove elemento
arrClear() Limpa array
arrContains() Verifica se contém
arrIndexOf() Índice do elemento
arrLastIndexOf() Último índice do elemento

Exemplo

frutas = [] r.arrAdd(frutas, "Banana") r.arrAdd(frutas, "Maçã") r.arrAdd(frutas, "Uva") for i in range(r.arrSize(frutas)): r.rPrintln(r.arrGet(frutas, i))
Banana Maçã Uva

💾 Arquivos

Salvando arquivo

r.rSaveFile("meu_arquivo.txt", "Conteúdo do arquivo")

Lendo arquivo

conteudo = r.rOpenFile("meu_arquivo.txt") r.rPrintln(conteudo)

Buscando URL

// Busca conteúdo da URL conteudo = r.rOpenFileWeb("https://api.example.com/dados") // Acessa código HTTP status = r.rOpenFileWebStatus() r.rPrintln(f"Status: {status}")

Executando programa

// Executa programa do sistema r.rOpenProgram("python3 script.py")
