Manipulação de Strings

Métodos para trabalhar com textos

Método Descrição Exemplo
strReplace() Substitui substring r.strReplace("Olá mundo", "mundo", "Megusta")
strLength() Tamanho da string r.strLength("Olá") → 3
strSubstring() Extrai substring r.strSubstring("Olá mundo", 0, 3)
strCharAt() Caractere na posição r.strCharAt("Olá", 0) → "O"
strIndexOf() Índice da substring r.strIndexOf("Olá mundo", "mundo") → 4
strLastIndexOf() Último índice r.strLastIndexOf("aaa", "a") → 2
strToLowerCase() Minúsculas r.strToLowerCase("OLÁ") → "olá"
strToUpperCase() Maiúsculas r.strToUpperCase("olá") → "OLÁ"
strEquals() Compara strings r.strEquals("Olá", "Olá") → true
strSplit() Divide string r.strSplit("a,b,c", ",")
strPadStart() Preenche início r.strPadStart("Olá", 6, "0") → "00Olá"
strPadEnd() Preenche final r.strPadEnd("Olá", 6, "0") → "Olá00"
strSearch() Busca regex r.strSearch("abc123", "\d+")
